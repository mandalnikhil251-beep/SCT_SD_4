# 🛒 E-Commerce Product Scraper — Task 04

A Python-based GUI application that extracts product information from an online e-commerce website and saves the collected data into a structured CSV file.

## 📌 Internship Task

**SkillCraft Technology — Software Development Internship**

**Task 04: E-Commerce Product Scraper**

## 🚀 Features

- Extracts product names
- Extracts product prices
- Converts prices from GBP to approximate INR
- Extracts product ratings
- Displays scraped data in a graphical user interface
- Accepts a website URL through the GUI
- Saves extracted data into `products.csv`
- Handles scraping errors
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Tkinter
- Requests
- BeautifulSoup
- CSV
